#  Power BI Portfoliom | Data Analitika Layihələri

Xoş gəlmisiniz! Bu repozitoriyada mənim data analitiki və Power BI tərtibatçısı olaraq hazırladığım interaktiv dashboard-lar, ETL (Power Query) prosesləri və qabaqcıl data modelləşdirmə layihələrim toplanmışdır.

Hər bir layihə real biznes suallarına cavab tapmaq, xam datanı təmizləmək və idarəetmə qərarları üçün vizual hesabatlar hazırlamaq məqsədilə qurulmuşdur.

## 🛠️ Ümumi Kompetensiyalar və Texniki Bacarıqlar
* **Data İnteqrasiyası və ETL:** Power Query vasitəsilə fərqli mənbələrdən (Excel, CSV) daxil olan xam dataların təmizlənməsi, tiplərin təyini, sətir və sütun transformasiyaları (Append, Merge, Unpivot).
* **Data Modelləşdirilməsi:** Relyasion verilənlər bazası strukturlarının analizi, Fakt və Dimensiya cədvəlləri arasında optimal *Star Schema* modellərinin qurulması, 1-to-Many əlaqələrinin və filtr istiqamətlərinin nizamlanması.
* **DAX (Data Analysis Expressions):** Biznes göstəricilərini (KPI) hesablamaq üçün dinamik metrikaların yaradılması, Time Intelligence funksiyaları ilə keçən ilin eyni dövrü (YoY) və böyümə faizlərinin analizi.
* **Məlumatların Vizuallaşdırılması:** Rəng harmoniyası gözlənilən, istifadəçi dostu (UI/UX) interaktiv vizual panellərin, dinamik filtrlərin (Slicers) və cədvəllərin dizayn edilməsi.
